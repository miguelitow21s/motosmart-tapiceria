Es el archivo latino de Google Fonts recortado con fontTools (`instancer`) a
lo que usa la tienda: peso 400 a 800 y ancho 75 % a 100 %. Pasa de 90 kB a
58 kB. Si el diseño necesita un peso 900 o un ancho mayor, hay que volver a
generarlo desde el archivo completo.
